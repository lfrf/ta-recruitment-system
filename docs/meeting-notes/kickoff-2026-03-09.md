## 1. Objective
- Start the EBU6304 group project with a clear scope, process, and evidence trail.

## 2. Project constraints
- The system must be built as:
  - a stand-alone Java application, or
  - a lightweight Java Servlet/JSP web application
- Data must be stored in text-based formats only:
  - `txt`
  - `csv`
  - `json`
  - `xml`
- No database is allowed.
- Agile methods must be used and evidenced.

## 3. Stakeholders agreed
- `TA Applicant`
- `Module Organiser (MO)`
- `Admin`

## 4. Initial in-scope features
- Applicant profile management
- CV upload
- Job browsing
- Job application
- Application status tracking
- MO job posting
- MO applicant selection
- Admin workload checking

## 5. Initial out-of-scope items
- Database integration
- Advanced framework migration
- External service integration
- Unexplainable AI features

## 6. Technical route decision
- Selected option: stand-alone Java application
- Reason: This option has lower implementation and deployment risk for the first assessment, is easier to demonstrate, and fits well with file-based storage.
