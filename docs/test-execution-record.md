# Test Execution Record

## 1. Purpose

This document is used to record the execution of test cases for the TA Recruitment System. It helps the team track testing progress, record pass/fail results, and keep evidence for later reporting, demonstrations, and acceptance testing.

## 3. Result Definition

- **Pass**: the actual result matches the expected result.
- **Fail**: the actual result does not match the expected result.
- **Blocked**: the test cannot be completed due to missing function, dependency, or environment issue.

## 4. Defect Recording Notes

When a test fails, the team should record:
- the related test case ID;
- a short description of the problem;
- the steps to reproduce;
- the observed result;
- the expected result;
- any screenshot or supporting evidence;
- the related GitHub issue number, if one is created.
