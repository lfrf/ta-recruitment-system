## Consistency rules
- Use the same status terms everywhere:
  - `Submitted`
  - `Accepted`
  - `Rejected`
- Use the same role names everywhere:
  - `Applicant`
  - `Module Organiser`
  - `Admin`
- Keep button labels short and action-based.
